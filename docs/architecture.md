# Architecture — UAG-core

## Boundary
Pure Rust model and utility layer.

## Modules
- `ids`: typed identifiers.
- `takg`: editable source graph.
- `uagl`: compiled IR.
- `graph`: traversal/query/index primitives.
- `ontology`: kinds, facets, planes, layers, profiles.
- `dialects`: dialect registry and official dialects.
- `validation`: diagnostics and rule primitives.
- `serialization`: YAML/JSON helpers.
- `schema`: versioning and migration.
- `error`: core errors.
